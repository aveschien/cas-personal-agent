# 明确行动可直接写入，输入按静默窗口聚合

PRD v0.3 要求协同承诺在影响他人前再做一次确认，并假设每条飞书消息形成一个即时处理回合。真实使用中，用户常把一个意思拆成多条文字，再补一张截图；逐条调用模型、逐条回复会打断输入，也会让后发附件失去上下文。用户同时明确授权：模型识别出的个人行动和协同承诺可直接写入滴答或飞书任务，不再要求二次确认。

决定：明确、可执行且负责人能唯一解析的行动直接进入对应事实源；歧义负责人、想法、转述和未触发预案仍不得写入。飞书入口先把每条原始消息持久化，再按短静默窗口组成一个输入批次，一批只调用一次 Pi、回复一次。用户可用 `立即回答`、`现在回答`、`马上回答` 或 `/now` 立即冲刷当前批次；连续输入还受最大等待时间约束，避免一直不处理。

这项决定取代 PRD v0.3 中“协同承诺总要二次确认”和“每条消息即时响应”的对应描述。它不授权 Agent 代表用户发送普通同事消息、邀请会议或修改已有外部承诺；这些操作仍需单独边界。
