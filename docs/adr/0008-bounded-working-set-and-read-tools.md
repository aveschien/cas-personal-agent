# 有界 Working Set 与单一 Pi 按需读取

连续对话需要恢复“那个、刚才那个、先放着”的指代，但不能再复制一套完整事实库。SQLite `working_set_entries` 每个逻辑会话最多保留 12 条近期 Project/Item 引用、未闭环问题和进入点；完整字段仍来自 Current State，长期历史仍来自 Hindsight。

Supervisor 在同一个 Pi loop 中提供三个受控能力：最多返回 10 条的本地状态查询、仅针对一个 Action Key 的外部刷新、以及仅在历史追溯时可用的有限记忆搜索。定向刷新在连接器空闲时本回合等候一次受限读取；已有同步运行或退避时保持持久化排队，并明确返回尚未核实。没有增加前置分类或指代模型。普通讨论的自动 Hindsight recall 被收窄到明确历史/偏好表达；当前注意力继续由确定性代码计算。

自然指代先按 Working Set 最近提及顺序提供候选。一个候选可直接延续，多个真实候选必须问一个最小澄清问题；固定命令不是用户接口。
