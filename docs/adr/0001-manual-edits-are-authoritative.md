# 人工修改优先于 Agent 推导的状态

用户可以直接在多维表格、滴答、飞书任务（后续还有企微日程）里修改工作状态。这些应用本身就是用户真实的工作面，所以人工修改是权威纠正：Agent 读到与自身摘要、推断、记忆或已生成操作相冲突的人工修改时，必须吸收并保留它，不得用旧信息覆盖。

2026-09-07 修订：原“MVP 不做后台轮询、只在前台按需读取”的限制已被本地 Current State + 后台变化采集取代。连接器有真实事件或游标时使用；没有时只做配置范围内、带预算的批量快照差异和定向核对，不虚构 change feed。普通回合读取 SQLite Current State；明确要求最新事实、状态不确定、执行或提醒依赖最新事实时才刷新相关对象。权威纠正进入版本化状态更新，晚到旧快照不得仅凭接收时间覆盖较新指令。
